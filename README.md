# Alieni nella Jungla

Sparatutto in terza persona nel browser (Three.js). Attraversa la giungla, sconfiggi la Regina Aliena e raggiungi l'uscita.

Apri `index.html` nel browser (serve internet per caricare Three.js). Funziona anche su telefono con i comandi touch.

- PC: WASD muovi, mouse mira, click spara, Shift corri, Spazio salta, E apri casse, Q cambia arma
- Ogni 2 casse compare una trasformazione: Drago di Fuoco o Lupo Folgore
